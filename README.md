# WattsTrack My Bike

Escopo de Layout para o Site da WattsTransportesOlá! Preciso criar uma página de rastreio para os nossos clientes que já compraram uma moto elétrica. O objetivo é ter um visual limpo e direto, inspirado no modelo abaixo:1. Identidade Visual e CabeçalhoCores Principais: Usar fundo amarelo e detalhes em azul (estilo a imagem de referência) ou adaptar para as cores oficiais da WattsTransportes.Logo: No topo esquerdo, deve aparecer a logo da WattsTransportes.Menu/Ações: Um menu simples ou ícone de perfil no canto superior direito.2. Caixa de Destaque do Rastreio (Card Principal)Código de Rastreio: Exibir em letras grandes e com fundo contrastante o código do pedido (Exemplo: WT123456789BR).Prazo Estimado: Um pequeno balão ou aviso ao lado do código indicando o tempo estimado (Ex: "Previsão: 5 dias úteis").3. Linha do Tempo Visual (Status da Entrega)Preciso de uma linha horizontal com 3 ícones circulares e azuis para mostrar o progresso:Ícone 1 (Caixa): Legenda "Pedido Preparado" ou "Postado".Ícone 2 (Caminhão/Moto): Legenda "A caminho" ou "Em transporte".Ícone 3 (Casa): Legenda "Entregue".Nota para o dev: A linha que liga os círculos deve mudar de cor (ficar preenchida) conforme o status atual do rastreio.4. Área de Avisos e Histórico DetalhadoAlerta de Atualização: Uma caixinha cinza ou amarela clara com um ícone de atenção para avisos importantes (como mudança de lote ou transportadora parceira).Histórico com Data e Hora: Listagem em ordem cronológica de onde o produto está (Ex: "20/03/2026 14:50 - Objeto em transferência para a filial regional É pra isso acontecer quero tipo no começo um login pra colocar cpf pra poder localizar
